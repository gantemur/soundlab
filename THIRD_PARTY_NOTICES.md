# Score provenance and third-party material

The application uses no externally hosted runtime libraries, fonts, audio
samples or sound recordings. Instrument sounds are generated locally.

The editable melody presets contain independent, simplified transcriptions
or excerpts of older compositions. Their source and variant descriptions are
shown in Compose and appended as comments to each editable score:

| Melody | Source / scope |
| --- | --- |
| Beethoven — Ode to Joy | [ABC melody transcription](https://abcnotation.com/tunePage?a=trillian.mit.edu%2F~jc%2Fmusic%2Fabc%2Fsong%2FOde_To_Joy%2F0000), G-major melody variant |
| Petzold — Minuet in G, BWV Anh. 114 | [Mutopia public-domain score](https://www.mutopiaproject.org/cgibin/piece-info.cgi?id=75); upper voice, one octave lower, repeats/ornaments omitted |
| Traditional — Lightly Row | [1927 songbook transcription](https://abcnotation.com/tunePage?a=trillian.mit.edu%2F~jc%2Fmusic%2Fbook%2FEverydaySongBook%2FEverydaySongBook1%2F0198); not a Suzuki edition |
| Mozart — Symphony 40, K. 550 | [Violin LilyPond source](https://github.com/musicologyman-teaching/mozart-k-550/blob/master/mozart-k-550-for-listening-i.ly); 20-bar first-subject excerpt, one octave lower, no accompaniment |
| Traditional — Frère Jacques | [Noctave CC0 score](https://noctavepiano.com/en/sheet-music/trad-frere-jacques/), one melody statement |
| Traditional — Twinkle / Ah! vous dirai-je, maman | [Noctave CC0 score](https://noctavepiano.com/en/sheet-music/trad-ah-vous-dirai-je-maman/), plain tune, no Suzuki variations |

These melodies are not modern copyrighted recordings, complete orchestral
scores or copies of a Suzuki edition. Public-domain status of an underlying
work does not confer rights to independently protected modern arrangements.

The full source rationale, adapted note ranges and ongoing Mongolian-song
research are recorded privately in `gantemur/soundlab-private/music/abc/`.
The MIT license covers the independently authored Sound Lab application
code and documentation; it is not a claim of ownership over the underlying
musical compositions, original editions or separately authored transcriptions.
