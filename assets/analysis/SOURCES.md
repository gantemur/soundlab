# Analysis recordings — sources, rights and processing (A2b)

These eleven files are *actual recordings or edits made entirely from recorded
foley*, not Sound Lab synthesizer output. They are stored locally on the Sound
Lab site, loaded only after a user chooses an example, and never uploaded from
a user's device. Source recordings were acquired 2026-11-07 UTC.

**Rights:** The Sound Lab MIT code license does **not** relicense third-party
recordings. The rights shown below apply to the audio. The Sound Lab UI links
the recording's creator/source and license individually. CC BY audio has
specific attribution obligations; these credits and change notes must remain
with every redistributed copy. CC0 creators are credited voluntarily.

Every published file was converted with FFmpeg to RIFF-WAV, mono, 22,050 Hz,
signed PCM16, and given a brief head/tail fade where indicated. The original
acquired file was an already compressed or edited *redistribution* in several
cases, so these are not lossless derivatives of the original master tapes.
Avoid drawing conclusions about the original equipment's absolute loudness
or spectrum above the 11,025 Hz Nyquist frequency of these teaching excerpts.
